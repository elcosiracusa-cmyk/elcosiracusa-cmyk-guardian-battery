# Battery Guardian

Android battery diagnostics and optimization assistant.

## Current real features
- Battery level and charging state
- Battery temperature
- Battery voltage
- Android-reported battery health
- Local Battery Score
- Top foreground apps from Android Usage Access
- Shortcuts to Android Battery Saver and battery optimization settings

Battery Guardian does not claim to force-stop other apps, overclock/underclock hardware, or change protected Android power policies without user action.

## Build
The GitHub Actions workflow builds a debug APK on every push to main.
